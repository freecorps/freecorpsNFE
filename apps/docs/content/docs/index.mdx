## Escolha o que quer fazer [#tarefa]

Você envia o XML de uma nota, ou a plataforma o recebe do fisco. O arquivo é validado e guardado como chegou, e vira um documento normalizado, com itens, eventos e valores em decimal exato. Cada mudança relevante pode virar um webhook assinado para o seu sistema. Escolha a tarefa e siga o guia dela; cada um diz o que é preciso antes, o que deve aparecer no fim e como recuperar uma falha.

## Ambientes, sem misturar [#ambientes]

No serviço hospedado, a importação e a emissão simulada rodam no ambiente de teste, chamado `sandbox`, pelo painel ou pela API. A única consulta ao fisco em produção é a [captura de NF-e](/docs/captura-nfe), da empresa que a ativa no painel. O que vale em cada um está em [Conceitos](/docs/conceitos#ambientes).

## O que a plataforma faz [#o-que-faz]

| Capacidade                                         | Estado                                                               |
| -------------------------------------------------- | -------------------------------------------------------------------- |
| Importação de NF-e modelo 55                       | Disponível, pelo painel e pela API                                   |
| Importação de lotes NFS-e no leiaute ABRASF        | Retirada; notas já importadas só para leitura                        |
| Consulta de documentos, itens, JSON e XML original | Disponível                                                           |
| Webhooks assinados com retentativas                | Disponível                                                           |
| Exportação privada de documentos                   | Disponível                                                           |
| Consulta de CNPJ, municípios do IBGE e NCM         | Disponível, sem indicar regularidade fiscal                          |
| Emissão e cancelamento de NFS-e                    | Só no sandbox, com transporte simulado e sem validade fiscal         |
| Captura de NF-e destinadas pela distribuição DF-e  | Em produção, para a empresa que a ativa no console, sem manifestação |
| Emissão automática a partir de cobranças do Stripe | Em construção                                                        |

<Callout type="warn" title="Fora da 1.0">
  Emissão com validade fiscal de qualquer modelo, emissão de NF-e ou NFC-e, cálculo tributário,
  captura de NFS-e, NFS-e na importação (nacional, ABRASF ou outros leiautes municipais), CT-e,
  MDF-e e SLA.
</Callout>

## Três regras que valem em toda a API [#regras]

1. **Dinheiro é texto.** Valores fiscais e quantidades chegam e saem como strings decimais exatas, como `"1500.00"`. Não converta para `Number`.
2. **Repetir não duplica.** Escritas aceitam `Idempotency-Key`. A mesma chave com o mesmo pedido devolve o resultado original.
3. **Aceito não é concluído.** Importações e emissões respondem assim que o pedido é aceito. Acompanhe o estado pela consulta ou pelos webhooks.
